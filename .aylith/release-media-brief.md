# Bindlume release media brief — 2026-09-25

Status: production plan, not a published changelog entry. The current source-owned catalog and
README call Bindlume an early Omarchy public alpha. The central
`/projects/bindlume/changelog` currently has no studio entries, so a release story must not claim
an existing film or finished accessibility/installer acceptance.

## First truthful story

“Find the shortcut, see the keys.” Follow a real Omarchy shortcut from the Bindlume search list to
the illuminated keyboard, then bookmark it. Show that live Omarchy bindings can differ from the
website's example data. Capture the running GTK app on a supported Lua-based Omarchy setup, using
a disposable or redacted profile. Do not stage desktop actions from the website demo as if they
ran on the viewer's system. The optional guide, global input access, agent controls, and memory
are separate opt-ins; do not imply they are enabled by installation.

The committed website includes 1000×670 native GTK screenshot pairs for Square, Rounded, and Neo
appearances with Omarchy and Chromium sets under `website/public/screenshots/`. These are useful
visual references and potential release stills, but the release capture must identify exact app
revision, source set, theme, display scale, and any demo data. The existing list-view stills do
not prove keyboard-only interaction, assistive-tech behavior, installer success, or a full journey.

## Film, narration, and poster

Produce matched light and dark screenshots and **separate real interaction videos** at the same
viewport and with equivalent shortcut data. Suggested Remotion beats: a search phrase; result
selection; the actual key chord illuminated; a bookmark becoming available; a quiet closing card
with the alpha/Omarchy scope. Animate the relationship between action and key, not invented speed
or accessibility claims. On-screen annotations should label action, source, modifier chord, and
bookmark state; captions must match the final narration and remain readable on both themes.

Use a licensed Cartesia voice selected for Bindlume, with actual audio provenance and separately
mixed light/dark exports. Draft narration: “A shortcut is easier to keep when you can see it. Find
an action by name, read its keys, then bookmark it for next time. Bindlume reads your current
Omarchy bindings alongside app shortcut sets. This is an early testing preview for Lua-based
Omarchy.” Time the final wording to verified footage; no Cartesia call or recording is claimed.

Design paired exceptional posters around a **real** illuminated chord, with the existing Bindlume
hero's warm dark/light atmosphere and one legible search-result label. The poster should be
recognizable at changelog-card size and clearly belong to the actual GTK product. Verify native
pixels, text contrast, caption timing, audio license, codec/streams, dimensions, duration, and
public byte hashes before attaching assets to a studio changelog entry. Real film, narration,
posters, full paired capture, and publication remain open.

## Product gate that media must not hide

Fresh supported Omarchy install/update/uninstall and keyboard-only/screen-reader exploration need
separate acceptance. The existing dirty installer, keyboard, agent, and System One work in the
original checkout has not been reviewed as shipped code. Keep the alpha scope visible until those
gates are met.
