# Bindlume logo

The selected mark is **11D / Linked chord**: three pressed keys connected within a constellation forming a lowercase b. The original reference and eight variants remain in the website logo studio.

`mark.svg` is the canonical, scalable artwork. Its fixed amber color works on light and dark backgrounds; the transparent background follows the surrounding surface.

To replace the logo, edit `branding/mark.svg`, copy it to `website/public/mark.svg`, and publish that website asset through the Sites source checkout. Run the normal app installer to update the About view and desktop icon. Keep the icon name `com.aylith.Bindlume` stable: it matches the existing application identity. No preferences or shortcut bindings need to change for an artwork update.

`wordmark.svg` is the alternative wide “Linked letters” artwork used in the landing header. The compact 11D icon remains the app icon and favicon. Logo explorations are retained under `website/design-archive/logos/`, outside the published site.
