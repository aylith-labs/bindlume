Ask it.

The built-in agent can change the app while you use it. Ask “Show theme shortcuts,” “Use a rounded dark look,” or “Bookmark this shortcut.” It searches real bindings and applies changes through the running app’s control API. Choose an installed agent or configure a direct Gemini, OpenRouter, Ollama, or compatible API connection.
